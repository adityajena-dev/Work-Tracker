# Work Planner

A simple personal work-planning web app built with React, TypeScript, and Vite.

The project was created as a practical way to learn and apply:

- React
- TypeScript
- Tailwind CSS
- Local Storage
- Component-based UI
- State management
- Responsive design

## Features

- Add and manage work
- Track completed work
- Plan daily workload
- Prioritize pending work
- Track daily capacity
- Record given-out work in batches
- View work history
- Backup and restore local data

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
- Local Storage

## Data

The current version is frontend-only and stores data locally in the browser using `localStorage`.

No backend or database is used yet.

## Project Status

This is a personal project and learning project.

The current version focuses on getting the workflow right, improving the UI, and testing the app in real use before moving to a backend and database.
